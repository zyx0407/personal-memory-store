写入 · 读取 · 蒸馏
写入三关
① 入口过滤：身份/偏好/稳定规则/长期目标才进核心
② 新旧判定：日期大的为准，旧行标「已废止」
③ 写入即归并：候选带「并入 → 片#条」
读取三查
① 答前必检：先 search 或直读分片
② 数字现跑：体积/片数/余量不写死
③ 来源锚：每条能追到出处
蒸馏
流水 → 候选「我的草稿」→ 确认 → 写核心/分片
没确认＝当场否决，原文沉流水
